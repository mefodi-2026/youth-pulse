# Изолированная облачная проверка — условия, не команда публикации

Доступный Firebase CLI/MCP видит только `molodeh-c523e`. Pages и develop Preview
используют его же; audit Preview не получил Firebase env, назначенные только
ветке develop. Простое копирование этих значений НЕ изолирует Firebase.
Ничего не создано, тариф и платные ресурсы не включены.

Перед облачной нагрузкой нужны:

1. Уже существующий отдельный тестовый Firebase-проект, разрешение на запись
   только тестовых данных, доступ на просмотр журналов и публикацию в него.
2. Anonymous Auth; RTDB в europe-west1 с теми же Rules; Functions Node 20
   в europe-west1. Если для Functions требуется подключение billing, это
   отдельное действие владельца, не разрешённое текущим заданием.
3. Web-конфигурация этого проекта в отдельном Vercel environment/Preview,
   без production credentials. Шаблон: `config/audit-staging.env.example`.
4. **Блокирующий предохранитель:** Functions сейчас жёстко привязаны к
   production `ROOM_DATABASE_URL`. Обычная смена `--project` НЕ изолирует базу.
   Нужен отдельно подготовленный исходник трёх действующих callable handlers
   с явным тестовым RTDB endpoint, проверенным на НЕproduction, и теми же
   политиками. Конфигурация example намеренно указывает несуществующий source,
   чтобы её нельзя было случайно развернуть с production endpoint.
5. Перенести только публичный каталог и создать тестового ведущего; участников
   подключать обычным анонимным клиентским путём. Не копировать реальные игры,
   учётные записи, имена или ответы.
6. Проверить проект/регион/RTDB на фронте и сервере, HTTP ответы одного гостя,
   запрет чтения чужих данных и подтверждение своего ответа. Только потом
   повторять 29/30/31, постепенный и одновременный старт/ответы.
7. Для защищённого Preview нужен обычный доступ вошедшего Vercel-аккаунта
   к проекту comanda1/youth-pulse-dev. Не использовать protection bypass
   secrets в адресах или исходниках.

Минимальное действие владельца: предоставить доступ к уже подготовленному
изолированному проекту и его Preview. Если такого проекта нет — сначала
согласовать создание и стоимость; текущая задача не разрешает это включить.
